# VayuDrishti

## AI-Powered Cyclone Intelligence & Decision Support System

**Live Demo:** https://vayu-drishti-wheat.vercel.app/

VayuDrishti is a cyclone intelligence prototype designed to visualize cyclone tracking, satellite observations, rapid intensification indicators, probabilistic forecasting, wind hazards, and district-level risk.

The project uses simulation/representative data to demonstrate how multi-source cyclone information can be converted into useful decision-support insights.

## Features

- Cyclone tracking and visualization
- Historical and 0–72 hour forecast tracks
- Multi-source satellite observation interface
- Rapid Intensification monitoring
- Wind-radius analysis
- District-level risk assessment
- Scenario simulation
- Advisory report generation

## To Run Locally

```bash
git clone <YOUR_REPOSITORY_URL>
cd VayuDrishti
```

## Install Dependencies

```bash
npm install
```

## Start the Application

```bash
npm run dev
```

The terminal will display the local URL, for example:

```text
http://localhost:8085
```
